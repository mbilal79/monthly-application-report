# Job Application Data Analysis using Google Sheet

## Project Overview
This project analyzes an agency’s online job application data using Google Sheet.

The main objective was to summarize and analyze monthly application trends using spreadsheet functions and custom tables.

## Questions Solved
- Total applications received each month
- Total number of applications received
- Highest and lowest application months
- Average number of applications per month

## Skills Used
- Data Cleaning
- Sorting and Filtering
- Spreadsheet Functions
- Data Summarization
- Custom Tables
- Analytical Thinking

## Tools Used
- Google Sheet

## Outcome
This project helped improve spreadsheet analysis and data organization skills commonly used in data analytics roles.
